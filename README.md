# OraVisionAI

OraVisionAI is an AI-assisted oral health screening and teleconsultation platform.

## Core Components

- Patient portal
- Dentist portal
- Administrator portal
- AI-based oral condition classification
- YOLO-based lesion detection
- Explainable AI (XAI)
- Medical screening history
- AI-generated reports
- Dentist assessment
- Dentist-patient communication
- Appointment management
- Teleconsultation
- Authentication and authorization

## Technology

### Frontend
- React
- Modern responsive UI
- Framer Motion
- Professional medical/dental visual design

### Backend
- FastAPI
- Python
- REST APIs

### Database
- PostgreSQL

### Authentication
- Firebase Authentication

- Google authentication

### Storage

### AI
